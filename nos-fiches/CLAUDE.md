## Rules

- Code like the makemepulse devs: `m-code-style` and `m-vue-style` skills. Double quotes, semicolons, PascalCase root class per component, Tailwind in templates, `<style scoped>` only for state-driven rules, all copy via `t()` in `src/locales/fr.json`, flow changes in `src/state/appMachine.ts`.
- Pure logic in `src/engine/` never imports Vue. Stateful logic reaches components through composables and the machine; small pure helpers (`formatQuantity`, `splitWords`, constants) are imported straight from `engine/` on purpose, no wrapper composable.
- Unit strings like `"selon le goût"` and `"pièce(s)"` in `engine/quantity.utils.ts` are data keys from data.json, not display copy.
- Gate before handing back: `npm run type-check && npm run lint && npm run build`, then check in the browser (desktop and 375 px wide). Run the `validator` agent on `src/` before delivering.
- `public/data.json` and `public/img/` are generated by `../scripts/` (see README). Don't edit them; extend the build scripts instead.

## Audience and health context

Users are François's parents, on a phone in the kitchen and a computer. Large tap targets, plain French, no jargon.

The site follows heart-healthy cooking guidelines: a coloured heart badge and ingredient swaps, **never a numeric health score or salt count**. Advice stays general and points to a doctor. The badge rules live in `../scripts/heart.mjs`.

Notes are personal data: EU hosting, no analytics, `noindex` stays.
